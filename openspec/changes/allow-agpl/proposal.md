# Allow AGPL-3.0 Candidates

## Why
Legal has approved AGPL-3.0 for the internal deployment scenario. Candidates rejected only because of AGPL should be reconsidered.

## What Changes
- Add AGPL-3.0 to accepted licenses.
- Reopen candidates whose only rejection reason was AGPL-3.0.

## Impact
The agent must use its durable rejection ledger instead of rediscovering candidates from scratch.
